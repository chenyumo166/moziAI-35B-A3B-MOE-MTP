MoziAI-35B-V3.7 正式发布！这是面向金融垂直领域深度优化的 35B MoE 多模态大模型：通过自研 MoziSmartBit 智能量化，将 350 亿参数压缩至 15.5GB（约 4.5 倍压缩比），保持 ≈99% FP16 精度——只需 20GB 显存的消费级显卡即可本地运行，支持 256K 超长上下文、视觉理解、工具调用与思维链推理，数据完全私有，免费使用。

什么是 MoziAI-35B-V3.7？

MoziAI-35B-A3B-MOE 是一款本地开源的金融 AI 多模态大语言模型（支持视觉和工具调用），由中国金融博主陈雨墨团队开发，基于 Ornith-1.5-35B-A3B（Qwen3.5-35B-A3B / Qwen3.6-35B-A3B 架构，MIT 许可）基础模型进行微调/蒸馏。

通过自主研发的 MoziSmartBit 智能量化技术，这款 350 亿参数的 MoE 模型被压缩至约 15.5 GB——在精度与大小之间实现最佳平衡，精度质量接近无损的 ≈99%。

除了保留通用人工智能能力外，该模型还专注优化金融垂直领域应用，包括：金融问答、量化编程、工具调用和通用编程。

模型开发者陈雨墨常使用该模型进行本地金融数据分析、量化策略研发、市场调研、文章撰写、整体项目推进、通用编程，以及通过 OpenClaw / Hermes 处理 256K 上下文任务。它可以在消费级 GPU 上本地部署，节省大量云端 Token 成本，实现 7×24 小时 Token 自由，同时确保本地数据的隐私与安全。

支持 llama.cpp、Ollama、LM Studio 以及其他主流推理框架。

为什么你需要一个本地大模型？

在金融行业，数据就是生命。把研报、财报、策略代码交给云端大模型，意味着你的核心数据在别人手里——API 调用费像流水一样花出去，还要担心数据泄露风险。

MoziAI 的答案很简单：把强大的 AI 装进你的电脑。V3.7 版本做到了「小体积、高精度、真免费」——这是为金融从业者、量化研究员、独立开发者量身打造的本地 AI 助手。

MoziSmartBit 量化：为什么「又小又强」？

传统量化对所有层统一压缩，精度损失明显。MoziSmartBit 针对 MoE 模型结构特点，采用智能差异化量化策略，在体积与精度间取得最优平衡：

量化格式模型体积精度保持说明
FP16（原始）≈70 GB100%原始 16bit 精度
MoziSmartBit≈15.5 GB≈99%本模型采用，最优性价比
Q4_K_M≈22 GB≈98%GGUF 标准 4bit
Q5_K_M≈24.7 GB≈99%更高精度
Q8_0≈36.9 GB≈100%无损

关键优势：训练增益 > 量化损失——训练后的 MoziAI-35B 在金融领域文本上 PPL 甚至优于训练前的 bf16 底座，幻觉与困惑更少。

三步上手：今天就能用上

① 下载模型

前往 HuggingFace / ModelScope / GitHub 下载 V3.7 目录下三个文件：主模型 GGUF + mmproj 视觉投影 + chat-template 模板。

② llama.cpp 启动

llama-server \
  -m V3.7/moziAI-35B-V3.7-MOE-MTP-Q4_K_M-Uncensored-Qwen3.6-35B-A3B-Ornith-1.5.gguf \
  --mmproj V3.7/moziAI-V3.7-35B-uncensored-heretic-mmproj-BF16.gguf \
  --chat-template-file V3.7/moziAI-V3.7-35B-chat-template.jinja \
  -c 262144 -ngl 99 -t 28 \
  --flash-attn auto --poll 0 \
  --reasoning on --reasoning-budget 1000 \
  --host 0.0.0.0 --port 8080 \
  --temp 0.6 --top-p 0.95 --top-k 20

③ 打开对话

浏览器访问 http://localhost:8080，开始你的本地金融 AI 之旅。也支持 Ollama / LM Studio 一键部署。
