## Обзор модели



MoziAI-35B-A3B-MOE — это локальная открытая финансовая AI мультимодальная LLM (поддерживает зрение и вызов инструментов), разработанная командой китайского финансового блогера Чэнь Юмо, дообучённая/дистиллированная на базе модели Ornith-1.5-35B-A3B (**архитектура Qwen3.5-35B-A3B / Qwen3.6-35B-A3B**, лицензия MIT). С помощью собственной технологии **MoziSmartBit Intelligent Quantization** модель MoE с 35B параметрами сжата примерно до **15,5 ГБ**, обеспечивая оптимальный баланс между точностью и размером с почти бесшумной точностью ~99%.



Помимо сохранения общих AI-возможностей, модель ориентирована на оптимизацию приложений в финансовой вертикальной области, включая финансовые вопросы и ответы, количественное программирование, вызов инструментов и общее программирование.



Разработчик модели Чэнь Юмо часто использует эту модель для локального анализа финансовых данных, разработки количественных стратегий, рыночных исследований, написания статей, продвижения проектов, общего программирования и задач с контекстом 256K через openclaw/hermes. Может быть развёрнута локально на потребительских GPU, экономя значительные затраты на облачные токены, обеспечивая токенную свободу 7×24 при гарантии конфиденциальности и безопасности локальных данных.



Поддерживает llama.cpp, Ollama, LM Studio и другие основные фреймворки инференса.



**Дата выпуска: 2026-08-21** | **Версия: V3.7**

- **Финансовая вертикальная специализация**: Глубокая оптимизация для финансовых Q&A, количественного программирования и вызова инструментов

- **MoziSmartBit Intelligent Quantization**: Собственная интеллектуальная квантизация, оптимальный баланс точности и размера, сжатие примерно до **15,5 ГБ**

- **Общее программирование**: Полноценная разработка, отладка кода, проектирование архитектуры, написание скриптов, охват Python/JS/TS/Go/Rust и других основных языков

- **Свободный вывод без цензуры**: Отсутствие цензуры контента, свободное обсуждение любых тем без ограничений безопасности

- **Улучшенное рассуждение**: Обучение на цепочке рассуждений для повышения качества рассуждений

- **Поддержка нескольких фреймворков**: Совместимость с llama.cpp, Ollama, LM Studio, Jan

- **Поддержка мультиагентных платформ**: Глубокая интеграция с OpenClaw, Hermes, OpenCode, Cursor, Windsurf, Claude Code, Codex и другими основными AI IDE и фреймворками агентов, нативная поддержка вызова инструментов и многошагового оркестрирования задач, готовность к использованию «из коробки»

## MoziSmartBit Intelligent Quantization



Традиционная квантизация использует единую точность для всех уровней. **MoziSmartBit Intelligent Quantization** применяет дифференцированные стратегии квантизации для оптимального баланса размера и точности.



### Эффект сжатия



Традиционная квантизация сжимает все части модели равномерно, что часто приводит к значительной потере точности. MoziSmartBit Intelligent Quantization использует собственную интеллектуальную стратегию сжатия, которая **обеспечивает значительное уменьшение размера при минимальной потере точности**:



- **Минимальные потери квантизации**: Выигрыш от обучения > потеря от квантизации. Обученная модель MoziAI-35B достигает лучшей PPL на финансовых текстах по сравнению с предобученной bf16 базовой моделью, снижая галлюцинации и перплексивность по сравнению с аналогичными AI-моделями

- **Сжатие ~4,5x**: Сжатие с ~70 ГБ (FP16) до ~15,5 ГБ, также значительно меньше, чем Q4_K_M (~21 ГБ), значительно снижая требования к VRAM и хранилищу

- **Дружелюбен к потребительским GPU**: Модель MoE с 35B параметрами, ранее требовавшая высококлассных GPU, теперь может плавно работать на GPU с 20~24 ГБ VRAM



### Сравнительные преимущества



**По сравнению с Q4_K_M (~21,2 ГБ)**: Меньше на ~30% (~15,5 ГБ), точность **выше**, чем у Q4_K_M, более низкий порог VRAM — плавно работает на среднеклассных потребительских GPU (24 ГБ).



**По сравнению с FP16 оригиналом (~70 ГБ)**: Сжатие ~4,5x, эффективное обучение + минимальная потеря квантизации (выигрыш от обучения > потеря от квантизации), возможность локального развёртывания с контекстом 256K на потребительских GPU вместо профессионального оборудования.

### Команда запуска llama.cpp



```bash

llama-server \

  -m V3.7/moziAI-35B-V3.7-MOE-MTP-Q4_K_M-Uncensored-Qwen3.6-35B-A3B-Ornith-1.5.gguf \

  --mmproj V3.7/moziAI-V3.7-35B-uncensored-heretic-mmproj-BF16.gguf \

  --chat-template-file V3.7/moziAI-V3.7-35B-chat-template.jinja \

  -c 262144 -ngl 99 -t 28 \

  --batch-size 2048 --ubatch-size 512 \

  --flash-attn auto \

  --cache-type-k q4_0 --cache-type-v q4_0 --kv-unified \

  --poll 0 --reasoning on --reasoning-budget 1000 \

  --host 0.0.0.0 --port 8080 \

  --temp 0.6 --top-p 0,95 --top-k 20

```

```bash
llama-server -m V3.7/moziAI-35B-V3.7-MOE-MTP-Q4_K_M-Uncensored-Qwen3.6-35B-A3B-Ornith-1.5.gguf \

```

```bash

llama-server \
```
