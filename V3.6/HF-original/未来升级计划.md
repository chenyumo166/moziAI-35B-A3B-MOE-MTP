## 二、知识蒸馏与训练计划

### 训练目标
针对主流量化交易平台的 API 和编程范式进行训练与知识蒸馏，使 MoziAI 能够：
1. **理解各平台 API**：不同平台的接口调用方式、数据格式
2. **生成策略代码**：自动为各平台生成符合其规范的策略代码
3. **回测逻辑**：理解各平台的回测引擎和评估指标

### 蒸馏内容

| 知识领域 | 具体内容 |
|----------|----------|
| **聚宽 API** | `get_history`、`order_target`、`count` 等接口，DataHandle 数据格式 |
| **掘金 API** | `get_instruments`、`subscribe`、`send_order` 等接口 |
| **米筐 API** | `initialize`、`handle_data`、`get_security_info` 等 |
| **天勤 API** | `tqsdk` 行情订阅、`Auth` 认证、`Api` 交易接口 |
| **Backtrader** | `Strategy` 类、`cerebro` 引擎、`plot` 可视化 |
| **Zipline** | `initialize`、`handle_data`、`pipeline` 因子 |

### 预期效果
- 用户描述策略思路，MoziAI 自动生成对应量化平台的策略代码
- 支持多平台代码转换（如聚宽 → 掘金、Backtrader → 天勤）
- 提供各平台回测结果解读与策略优化建议
