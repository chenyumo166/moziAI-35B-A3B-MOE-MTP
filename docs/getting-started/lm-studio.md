# LM Studio 使用指南

本文档介绍如何在 LM Studio 中使用 MoziAI-35B 模型。

---

## 步骤

### 1. 安装 LM Studio

从 [LM Studio 官网](https://lmstudio.ai/) 下载并安装。

### 2. 导入模型

1. 打开 LM Studio
2. 进入 **My Models** 页面
3. 将 `.gguf` 模型文件拖入 LM Studio 窗口，或点击导入按钮
4. 模型文件：`moziAI-V3.6-Qwen3.6-35B-A3B-Ornith-MoziSmartBit-Q4_K_M-Uncensored.gguf`

### 3. 配置对话模板

1. 在模型设置中找到 Chat Template 配置
2. 将 `moziAI-V3.6-35B-chat-template.jinja` 的内容复制到模板配置中
3. 保存设置

### 4. 开始对话

1. 进入 **Chat** 页面
2. 选择 MoziAI-35B 模型
3. 点击加载，等待模型加载完成
4. 开始对话

---

## 多模态配置

LM Studio 支持多模态模型：

1. 确保导入的 mmproj 文件：`moziAI-V3.6-35B-uncensored-heretic-mmproj-BF16.gguf`
2. 在聊天界面点击图片按钮上传图片
3. 输入问题发送

---

## 推荐设置

| 选项 | 推荐值 | 说明 |
|------|-------|------|
| 上下文长度 | 262144（根据显存调整） | 256K 长上下文 |
| 温度 | 0.6 | 平衡创意与准确性 |
| Top P | 0.95 | 核采样阈值 |
| Top K | 20 | 截断采样（V3.6 优化） |
| GPU 层数 | Max | 全部层加载到 GPU |
| 批量大小 | 2048 | 推荐值 |

---

## 显存配置建议

| 显存 | 推荐上下文 | 说明 |
|------|-----------|------|
| 16 GB | 32K ~ 64K | 纯文本推理 |
| 20 GB | 64K ~ 128K | 可尝试视觉（短上下文） |
| 24 GB | 128K ~ 256K | 视觉+中长上下文 |
| 32 GB+ | 256K 满配 | 推荐配置 |

---

## 注意事项

- 首次加载需要一些时间，请耐心等待
- 如果显存不足，可以减少上下文长度和 GPU 层数
- 多模态功能需要 LM Studio 较新版本支持
- 如需完整功能（工具调用、推理链等），推荐使用 llama.cpp
